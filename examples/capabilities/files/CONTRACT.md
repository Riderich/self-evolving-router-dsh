# Public file operations

Public files only, matching the host snapshot (hidden entries, links, node_modules and vendor omitted). Explicit subdirectories preserve case. Default root is /testbed; default recursion is false. Recursion must be explicit. Excluded directory names are case sensitive. Unknown constraints and conflicting requests abstain.

text.count_newlines counts newline bytes, including zero for an unterminated final line; files.list returns sorted relative file paths. File extensions are case sensitive when explicitly supplied as a glob. Parsing is deterministic and handles recognized English/Chinese keywords, synonyms and grammar in varied order. It is not a general natural-language parser. Source evidence currently records the entire interpreted request; finer field spans can be developed inside the package. Other operations are unsupported and may be developed by the agent.

Development assertions in tests/cases.json are manually authored seed examples, not hidden benchmark oracles. Production filesystem writes and cross-turn references are not supported by this seed.
